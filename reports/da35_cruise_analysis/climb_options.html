Which option addresses which problem?

  1. Limit takeoff throttle: set TKOFF_THR_MAX=75 in a separate simulation profile. It caps the commanded throttle during takeoff; 75% command is not 75% shaft power. This tested setting approaches the recorded climb rate, but changes the inputs from the actual flight and increases time to +50 m. Cruise settings are unchanged.
  2. Reduce commanded pitch: the AUTO mission's takeoff minimum is 12°. Lowering that minimum to 5° alone does not restrict a higher TECS demand. Adding TECS_PITCH_MAX=10 limits the navigation pitch request, with the existing +4° pitch trim still applied downstream. Pitch improves, but excess power produces more airspeed: almost 30 m/s in this test. This is not an effective standalone way to match climb.
  3. Lower the TECS climb setting: TECS_CLMB_MAX=2 does not impose a 2 m/s takeoff cap in this pinned ArduPlane 4.5.6 run. Takeoff pitch prioritizes airspeed, and the takeoff logic imposes a minimum pitch. Its role in ordinary altitude tracking differs from takeoff. Changing TKOFF_LVL_PITCH would target TAKEOFF mode rather than the AUTO mission command used here.
  4. Improve physical fidelity while keeping actual parameters: retain the shared BIN-matched configuration, match the real mission/controls and loading, then investigate full-power shaft output, propeller thrust, drag and flap effects. The model's 4.5 hp rating is an unverified seed assumption. Cruise RPM calibration does not identify full-throttle thrust. Do not use a climb match alone to select new aerodynamic coefficients.

The shared settings in config/sitl.parm remain matched to the BIN snapshot. config/models/tig_da35_cruise.parm adds the approved 75% takeoff limit for this model. No engine or aerodynamic coefficients were changed. The experiments do not establish broad fidelity or validate landing behavior, flap aerodynamics or electric assistance.

To repeat the tested throttle-limited simulation with its isolated parameter file:

python3 scripts/run_sitl.py --model tig_da35_cruise --name my_climb_test --param-file runtime/da35_climb_options/inputs/throttle_cap_75/sitl.parm --profile --duration 75

Recreate all four experiments: python3 scripts/investigate_da35_climb.py --run. Redraw saved results without flying again: python3 scripts/investigate_da35_climb.py.
